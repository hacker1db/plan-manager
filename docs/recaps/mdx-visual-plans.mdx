Plans can now be written as **MDX**: ordinary Markdown with typed review blocks such as file trees, split diffs, data models, endpoint contracts, flows, layers, and open questions. The local dashboard and the hosted viewer render them the same way. This lets plans and recaps produced by the new `visual-plan` and `visual-recap` skills live as plain `.mdx` files in Git, instead of HTML exports or a hosted database.

The key decision is that MDX is **parsed, never compiled or evaluated**. `remark-mdx` turns the source into an AST. Each capitalized JSX tag is looked up in a registry of allowed blocks, and its props are read from the ESTree as static literals. Imports, exports, `{expressions}`, variables, spreads, and unknown tags all render as inline error cards. The same registry generates `plan blocks`, so agents author from the live catalog, and `plan check` reports the same errors with a non-zero exit for CI.

<Column label="Before">

- Plans are `.md` only.
- Local: Pandoc → HTML → regex sanitizer.
- Hosted: `react-markdown`, raw HTML skipped.
- Structured content is a hand-written table or a fenced code block.

</Column>
<Column label="After">

- Plans are `.md` or `.mdx`, identified by one slug.
- MDX: one React renderer for both surfaces, with no Pandoc needed.
- Markdown plans render exactly as before.
- Structured content is typed blocks, validated by `plan check`.

</Column>
</Columns>

<Callout tone="decision" title="Frontmatter, not the database, carries the format">
Hosted plans are stored as raw source in Blob storage. Reading `format: mdx` from the frontmatter avoids a schema migration and keeps `plan push` unchanged. Writes to `.mdx` files stamp the key automatically. Push refuses an `.mdx` file that lacks it, so the hosted site never shows MDX as raw Markdown.
</Callout>

<Callout tone="decision" title="Tabs are CSS-only">
The local dashboard injects static HTML, so Tabs use radio inputs and `:checked` selectors instead of client state. The same markup works on the hosted portal without hydration. The stylesheet supports up to 12 tabs per block.
</Callout>
